## Day3作业

### 问题一
> 默写 GPIO 8 种工作模式及各自适用场景。

| 工作模式   | 适用场景                     |
| ------ | ------------------------ |
| 浮空输入   | 外部有明确高低电平驱动的信号，如 UART的RX |
| 上拉输入   | 按键检测，此时按键一端接GPIO，一端接GND  |
| 下拉输入   | 按键检测，此时按键一端接GPIO，一端接VCC  |
| 模拟输入   | ADC信号采集                  |
| 推挽输出   | LED灯的控制                  |
| 开漏输出   | 软件模拟I2C                  |
| 复用推挽输出 | SPI协议中的SCK和MOSI引脚        |
| 复用开漏输出 | 硬件I2C外设时SDA线需要配置为复用开漏输出  |

### 问题二
> 用自己的话解释「推挽 vs 开漏」，各举 1 个应用场景。

推挽输出是GPIO主动输出高低电平，适用于输出PWM波形，控制LED等场景；开漏输出只能被动拉低电平，输出1需要依靠上拉电阻，I2C协议要求SDA线上设备处于开漏输出模式，防止短路现象。
